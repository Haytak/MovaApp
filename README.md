# Mova App 🌍

[Українська версія нижче](#ua-опис)

## EN Description
**Mova App** is a lightweight Windows utility that follows your text cursor (caret) and shows a small flag indicating your current keyboard layout. No more typing a whole sentence only to realize you were using the wrong language!

### Features
- **Smart Tracking**: The flag follows the text cursor in real-time across most applications (Browsers, Word, Notepad, etc.).
- **Vector Flags**: Beautiful, high-quality vector flags for dozens of languages.
- **No Russian Support**: Explicitly excludes support for the Russian language.
- **404 Mode**: Shows a "404" indicator for unsupported layouts.
- **Auto-startup**: Easily toggle "Run on Windows startup" from the system tray menu.
- **Lightweight**: Minimal CPU and RAM usage.

### Important Note
This project was **created with the help of AI** (Trae IDE & Gemini 3.5 Flash).

## Installation / Встановлення
1. Download the latest `MovaApp.exe` from Releases.
2. Run it. The app will appear in your system tray.

## UA Опис
**Mova App** — це легка утиліта для Windows, яка слідує за вашим текстовим курсором (кареткою) і показує маленький прапор поточної розкладки клавіатури. Більше не потрібно видаляти цілі речення, написані не тією мовою!

### Можливості
- **Розумне відстеження**: Прапор слідує за курсором у реальному часі в більшості програм (браузери, Word, блокнот тощо).
- **Векторні прапори**: Якісні векторні зображення для десятків мов.
- **Жодної підтримки російської**: Принципова відсутність підтримки мови агресора.
- **Режим 404**: Показує індикатор "404" для непідтримуваних розкладок.
- **Автозапуск**: Можливість увімкнути запуск разом з Windows прямо з меню в треї.
- **Легкість**: Мінімальне споживання ресурсів процесора та пам'яті.
